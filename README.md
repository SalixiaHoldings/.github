# Salixia Holdings GitHub configuration

This repository contains public GitHub organization configuration for **Salixia Holdings**.

## What lives here

- [`profile/README.md`](profile/README.md) — renders as the public [Salixia Holdings organization profile](https://github.com/SalixiaHoldings).
- Shared organization-level GitHub files, templates, and community configuration may be added here as needed.

This repository is organization infrastructure rather than a Salixia product or service. Public engineering projects live in their own repositories and are associated with the Salixia operating company responsible for them on the organization profile and in project documentation.
